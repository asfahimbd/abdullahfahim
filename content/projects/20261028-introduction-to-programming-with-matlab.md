1\.

Launch MATLAB and configure working directories/folders for project organization.

2\.

Execute arithmetic and mathematical commands in the MATLAB Command Window and locate help documentation for unfamiliar functions and commands.

3\.

Define and apply core computer science terminology related to syntax rules (statements) and execution methods (interpreted vs. compiled).

4\.

Write, edit, and save MATLAB programs as M-files using MATLAB's built-in editor.

5\.

Generate basic data visualizations (e.g., plots and graphs) using MATLAB's visualization tools.
